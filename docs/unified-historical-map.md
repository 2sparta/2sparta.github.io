# Єдина історична мапа

Замість 23 перемикачів країн і регіонів атлас має одну мапу світу,
одну дату та пошук держав і міст. Старі посилання з `view=poland`,
`view=spain`, `view=england` тощо відкривають спільну мапу зі збереженою
датою. Зміна дати не скидає масштаб; кнопка «Показати весь світ» повертає
камеру до світового огляду. Міста з’являються під час наближення.

Попередня світова основа існувала лише для 500–1400 років. Пізніша мапа
складалася з часткових схем із прямими обрізаннями та незалежними
накладаннями. Тепер світова основа має 42 джерельні зрізи від 500 року
до н. е. до 1994 року. Разом із регіональними переходами індекс містить
164 дати. Обирається останній джерельний зріз, не пізніший за вибрану
дату; річна або місячна точність джерела залишається видимою.

`python scripts/build-world-atlas.py` (Shapely 2.1.2) відтворює дані з
pinned Historical Basemaps і наявних регіональних файлів. Пошкоджені
полігони нормалізуються, контури обрізаються маскою суходолу, а точніші
регіональні полігони вирізають перекриття сусідніх держав. Прямокутні
маски не використовуються. Замість завантаження всіх мап браузер бере
одну світову основу й одну поправку, з незалежним кешуванням. Геометричні
операції виконуються під час підготовки даних, а не під час руху повзунка.

Збережено датовані поділи Речі Посполитої, українські історичні землі,
козацькі та окупаційні шари, місячні фронти в Іспанії, авторські регіональні
контури й редактор спільних кордонів. Редактор зберігає наявні річні
інтервали, перевірку прав і ревізій. Нові правила або колекції Firebase
не потрібні. До 395 року ручний редактор, як і раніше, не застосовується.

Назву `White Russia` у світовому зрізі 1930 року виправлено на `USSR`;
посилання на підставу виправлення наведене в повідомленні про джерела.

## Межі точності

Світова база містить оглядові держави, культурні ареали й залежності.
Це не точна щоденна політична мапа. Наприклад, для 1806 року світова основа
має дату 1800, а не вигадану щоденну реконструкцію наполеонівських воєн.
Світова війна також не має щоденної реконструкції. Нейтральні ділянки —
прогалини джерел. Береги й річки є сучасними фізичними орієнтирами.

Джерела, атрибуція, ліцензії, контрольні суми та локальні обмеження:
`public/atlas/world/NOTICE.md`, `manifest.json` і відповідні регіональні NOTICE.
Старі дані збережено для відтворюваності; схематичні шари Німеччини,
Наполеона, античності та островів у спільному полотні не використовуються.

## Перевірка

- `node --experimental-strip-types --test tests/world-atlas.test.ts`
- `npm run test:school-tools`
- `npm run test:atlas-ui`
- `npm run test:commonwealth-ui`
- `npm run test:spain-ui`
- `npm run typecheck`
- `npm run build`

Географічні перевірки включають контрольні міста, відсутність Польщі
далеко на сході у 1500 році, попередній день кожного поділу й сам день
переходу, припинення візантійського шару після 29.05.1453, місячні фронти,
календар без нульового року, високосні роки та SHA-256 всіх нових файлів.
Інтерфейс перевірено з реальними даними на 1440/390 px у світлій і темній
темах: пошук, масштабування, перемикання днів, поділів і фронтів, відсутність
горизонтального переповнення та помилок виконання.

## Дослідження мапи та маршрути

- «Порівняти дві дати» використовує першу дату над спільною мапою й другу в панелі дослідження. Приклад задає 05.08.1772 та 24.10.1795. Бурштинові ділянки показують зміну належності; натискання відкриває обидві держави й дати.
- Web Worker порівнює відомі політичні контури з урахуванням шкільних правок. Якщо світова основа старіша за вибраний рік, її контури виключаються з порівняння: залишаються датовані регіональні уточнення та шкільні правки. Це явно позначено біля результату. Незмінені території вилучаються, потім зіставляються втрати й набуття. Прогалини даних не вважаються завоюваннями. Окупаційні й тематичні ареали не прирівнюються до державних кордонів. Число ділянок — число геометричних фрагментів, не історичних анексій. Різна точність джерел може давати дрібні відмінності; доступні зрізи та неповний розрахунок позначені біля результату.
- «Події на мапі» вмикає битви, договори й повстання. У звичайному режимі період — вибраний рік ± задана кількість років; у порівнянні — проміжок між двома точними датами. Для подій без точного дня враховується перетин усього року з періодом.
- Початкова добірка: 14 подій для маршрутів «Поділи Речі Посполитої», «Козацькі повстання», «Падіння Візантії». «Далі» й «Назад» змінюють дату та ракурс; останній крок вимикає «Далі». Приблизні місця та дати позначені у картках. Для події, відомої лише за роком, 1 січня використовується для навігації, а не як твердження про точний день. Картки містять описи, наслідки й посилання на джерела. Це тематична добірка, не повний каталог усіх історичних подій.

## Мапа у статті

У редакторі матеріалу додайте віджет «Інтерактивна історична мапа». Задайте дату, центр, масштаб 0…8 та доступні шари. Пересувайте й масштабуйте попередній перегляд; «Зберегти цей ракурс у віджеті» переносить поточний центр і масштаб у налаштування. Після вставлення всі параметри зберігаються у тілі матеріалу стандартним механізмом віджетів. Некоректну дату, координати, масштаб і невідомі шари зберегти неможливо.

Читач може рухати мапу, змінювати масштаб, перемикати дозволені шари, відкривати події та відновлювати початковий вигляд. Це не змінює матеріал. Фрагмент використовує спільні локальні геодані, кеш і шкільні правки атласу. Період подій у фрагменті — ±10 років від дати автора.

Перевірки: `npm run test:atlas-learning`, `npm run check:atlas-learning-ui`, `npm run typecheck`, `npm run build`. Браузерна перевірка використовує ізольовану тестову сторінку з локальним зберіганням статті та реальними геоданими, без запитів до шкільних записів. Тимчасовий HTML видаляється після перевірки; тестовий вхід не входить у публічний застосунок.
