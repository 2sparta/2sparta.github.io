# Відображення домашніх завдань

У «Завдання → ДЗ» та на дошці класу використовується спільна стрічка HomeworkStream. Дизайн зберігає зелені й кремові кольори платформи: компактні картки з кольором предмета, терміном, розгорнутими деталями й вкладеннями. Інтерфейс адаптується до темної теми й телефона.

- Пошук у назві, предметі, описі та імені автора.
- Предмети з лічильниками: бічна панель на комп’ютері, випадаючий список на телефоні.
- Групування за предметами або за термінами: термін минув, сьогодні, завтра, наступні 7 днів, пізніше, без терміну, виконано.
- Терміни — календарні дні за Києвом. Завдання на сьогодні залишається актуальним до завершення дня; перехід на літній/зимовий час не зсуває дати.
- Позначки «Виконано» використовують наявний Firebase checklist учня. Це особисті позначки, не підтвердження здачі чи оцінки вчителя.
- Учитель зберігає доступ до журналу та видалення з підтвердженням. Права публікації й видалення на дошці класу не змінюються.
- Немає нових колекцій Firestore чи змін правил доступу. Помилки завантаження/збереження показуються з повторною спробою.

Перевірки: npm run test:homework та npm run test:homework-ui. Загальні перевірки: npm run typecheck, npm run build.
