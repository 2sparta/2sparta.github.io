# Класний простір

Шкільна платформа: вхід учителя й учня, школи, класи, розклад, завдання, оцінки, оголошення, чат і самоврядування.

## Локально

```bash
npm install
npm run dev
```

Відкрийте http://localhost:8080

Без `DATABASE_URL` дані лежать у вбудованій базі (зникають після перезапуску). Для постійних даних вкажіть Postgres:

```bash
DATABASE_URL="postgresql://..." npm run dev
```

## GitHub + хостинг (Vercel)

1. Створіть репозиторій і залийте цей архів.
2. У Vercel: Import Git Repository, framework залишіть як є (збірка вже під Nitro/Vercel).
3. Build command: `npm run build`
4. Змінні середовища:
   - `DATABASE_URL` — рядок підключення Postgres (Neon або інший). Без нього на serverless дані не зберігаються між запитами.
   - `VITE_AUTH_ENABLED` — `true`
   - `BETTER_AUTH_SECRET` — довгий випадковий рядок
   - `BETTER_AUTH_URL` — публічна адреса сайту, наприклад `https://your-app.vercel.app`

Після деплою: учитель реєструється, створює школу. Учень реєструється і прив’язується 6-значним кодом з вкладки «Учні», або після входу натискає «Відкрити демо як Максим».
